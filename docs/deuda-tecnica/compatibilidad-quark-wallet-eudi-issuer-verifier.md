# Compatibilidad quark-wallet con issuer y verifier EUDI

**Objetivo:** que el holder mobile (`quark-wallet`) sea compatible con la emisión y verificación del ecosistema EUDI Wallet de referencia.

- Issuer: `https://issuer.eudiw.dev/`
- Verifier: `https://verifier.eudiw.dev/home`
